# Product Backlog

This is the shared place for product ideas that are useful but not part of the immediate build.

## Community Resources

- Resource search across title, description, and comments once problems have enough resources.
- Nested comment UI using the stored `parentCommentId`.
- Admin moderation dashboard for hidden, reported, deleted, and verified resources.
- Better ranking with Wilson score and richer time decay after adding downvotes or more engagement signals.
- Playable YouTube embeds with privacy review.
- Richer contributor reputation: Contributor, Top Contributor, Expert.
- Points for solving questions and for high-quality resource contributions.
- Admin tools to restore hidden resources and mark official recommendations.
